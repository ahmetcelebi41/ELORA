# 2. HAKKIMIZDA SAYFASININ TEMEL AMACI

Hakkımızda Sayfası, Ana Sayfa’daki kısa marka anlatımını tekrar etmek için değil; Elora’nın kimliğini, yaklaşımını, bakım anlayışını ve fiziksel atmosferini daha derin anlatmak için kullanılacaktır.

Temel kullanıcı akışı:

> **Elora kim? → Nasıl düşünüyor? → Kullanıcıya nasıl bir deneyim sunuyor? → Mekân bu deneyimi nasıl destekliyor? → Bakım anlayışı nasıl işliyor? → Randevuya ilerle**

Sayfa:

- kurumsal tarihçe,
- sahte kuruluş hikâyesi,
- ekip tanıtım kataloğu,
- başarı / sertifika vitrini,
- hizmetler sayfasının tekrarı

gibi görünmemelidir.
